Use `Tag` for structural micro-labels — "Pillar 1", "03 · Open Graph", "🔥 Roast".

```jsx
<Tag>Pillar 1</Tag>
<Tag tone="outline">AARRR check-up — 3 min</Tag>
<Tag tone="red">Roast</Tag>
```

Use `ModeTag` instead when the label states which run the user is in, and `PillarChip` when it carries a score. `tone="red"` is for roast mode only.
