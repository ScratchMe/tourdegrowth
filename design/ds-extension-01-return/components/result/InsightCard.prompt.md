Use `InsightCard` under a `MetaLabel wide` eyebrow — "Strengths", then "Where you're losing time". Two of each is the working maximum.

```jsx
<MetaLabel wide>Where you're losing time</MetaLabel>
<InsightCard pillar="Retention" score={8} kind="weakness">A weekly-use tool with churn concentrated in the first month…</InsightCard>
```

Each card names what was answered, then one concrete next step. Never more than one paragraph, never a bulleted list, and never a card without a score in its header — the number is what makes it credible.
