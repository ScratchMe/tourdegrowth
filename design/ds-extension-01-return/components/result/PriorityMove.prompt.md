Use `PriorityMove` at the end of a deep-dive result, after the insight cards and before the actions.

```jsx
<PriorityMove>Instrument week-4 retention by cohort this month, before any new acquisition spend.</PriorityMove>
```

One sentence, one action, a stated timeframe. Dashed red distinguishes it from the solid red wash of a weakness: solid = what is wrong, dashed = what to do. Never ship two.
