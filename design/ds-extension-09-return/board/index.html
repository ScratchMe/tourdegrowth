The engine's money — every state

Brief 09's states, drawn from the components' own source, every figure computed by one replica of the engine's money (money.js). Each opens at its width (390 or 1280), in English or French; every one exists in both languages from the same components.

Serve this folder over http (ES modules do not load from file://), e.g. python3 -m http.server from the project root, then open design/ds-extension-09-return/board/index.html. “Key” marks the key screens the brief asks for (FR 1280, EN 390); “measures” marks today's board, redrawn only to measure what the money adds.
