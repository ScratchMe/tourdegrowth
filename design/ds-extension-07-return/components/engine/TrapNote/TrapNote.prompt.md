TrapNote — design system extension 07. The trap, where it changes what one types.

Q8. Today the trap sits inside "Where to find it", folded, after the value:
a person types the number, then (maybe) learns that GA4's "Referral" is not a
customer's recommendation. Every trap in the catalogue is about what to put
in the box — which count, which period, which tool's definition — so **the
trap is shown before the value, open**.

## Rules

- Text **word for word** from the catalogue (CATALOGUE.md): the expertise is
  not rewritten. Only the label is new.
- Advice, so a **dashed red edge** (constraint 5): never a wash, never a
  solid red edge (those are a diagnosis), never a Card.
- **One per number.** Hybrid engines add the hybrid trap inside the same
  note, under "When you sell both ways".
- When the trap says to write something in your definition (3 of the 35
  traps do: sign-up rate, activation rate, lead-to-opportunity rate), it
  carries the quiet "Write your definition": it
  opens "Your definition and a note" (Disclosure `open`) and moves focus to
  that text area — the person asked for that move.
- The "To repair" text of "I can't find it" uses the same note (it is
  advice too), with its own label.
