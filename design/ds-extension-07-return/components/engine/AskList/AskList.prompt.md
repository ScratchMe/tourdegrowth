AskList — design system extension 07. The requests, in one step.

Today "To go and get (5)" is folded at the bottom of the board: requests by
role with "Copy the request", and "Do it yourself" grouped by effort or by
tool. Q11 asks whether the journey could start with what to ask for.

**Proposal**: the numbers whose effort is "Ask someone" are not one screen
each in the first pass. After the quick numbers (5 minutes each), NextStep
offers "Copy your {n} requests →": this screen, one card per role, each
with its request and "Copy the request". Antoine's own sentence is its lead:
*send the requests today, fill in the rest while waiting.*

## Rules

- **One request per role**, covering that role's numbers; copying it
  stamps **each** number with the request and its date (the model keeps one
  request per number, as today).
- A copied request shows its date on a **dashed edge** (pending).
- "Do it yourself" is not here any more: it is the numbers list, in the
  order NextStep follows.
- One primary: "Sent, next number →". The copy buttons are secondary.
- Copy is the only way out of the device for a request, and the person
  does it: nothing is sent (constraint 10).
