WhereToFind — design system extension 07. Each tool and its path, one tap away, without making the screen tall.

Q8. Closed by default; **its summary names the tools** ("Where to find it ·
GA4 · Mixpanel or Amplitude · Product database"), so a person knows whether
it is worth opening without opening it. Open: tool, then its path, as the
catalogue prints them; then "Also in GA4: …".

## Rules

- Paths **word for word** from the catalogue.
- The person's tools (Settings → Your tools) come **first**, tagged "your
  tool" (Tag neutral). Without tools chosen, catalogue order.
- The tool name is printed once (today's sheet prints "Mixpanel · Mixpanel
  or Amplitude": the tool id and the catalogue's label both).
- "Also in {tool}" links open those numbers' screens. Each link is a 44px
  row; they are ink, not `--text-link` red, so the screen's reds stay the
  trap (advice) and a verdict (diagnosis).
- The trap is **not** in here any more (TrapNote, above the value). The
  hybrid trap neither.
- Open on its own only through `open` (Disclosure delta): when the person
  chose tools in Settings and this number is filled from one of them.
