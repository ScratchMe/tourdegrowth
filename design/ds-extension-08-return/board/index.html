The header, compact — every state

Brief 08's header, drawn from this return's own SiteHeader and SpaceBand over a stand-in page that really scrolls. Each link opens one page at one window size, at the top (full) or scrolled (compact). A frame of exactly that size is drawn when your window is another size, with buttons to scroll it down and back up.

Serve the project over http (ES modules do not load from file://), e.g. python3 -m http.server from the project root, then open design/ds-extension-08-return/board/index.html. Parameters: page, lang, w, h, at=scrolled, focus=1, hover=pill|primary, motion=reduce, slow=10, play=1, enhance=off, closed=engine|game. The specs: README.md, MOTION.md.
